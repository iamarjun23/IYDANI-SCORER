  1. Click the svara you want to move.

Rows are sthayis, columns are svaras. A key writes one svara, so putting a key on a second svara takes it off the first.

New Time Signature

Write the division as its groups counted in the chosen symbol: 3+2+2 is seven of them, grouped three-two-two. Every group edge draws a lighter divider inside the division and takes a metronome accent. A bindu is always one beat — counting in a smaller symbol just types the same box in a different note value, and a time signature is always printed over 4.
